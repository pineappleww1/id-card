# Lin-creat · 3D 吊牌个人页

一个可以用鼠标或手指拖着甩的 3D 工牌，底下是一行超大的名字。右侧有一个工具栏，可以直接在网页上改名字、卡套里的三页和绳子颜色。
做法参照了 samfcheng.com 的设计：three.js 负责画 3D，Rapier 负责物理（重力、挂绳拉扯、甩动）。
代码是我们自己从头写的，没有用原作者的代码。

## 怎么跑起来

```bash
cd ~/Lin-find/Lin-creat
npm install      # 第一次才需要
npm run dev
```

终端里会打印一个地址（一般是 http://localhost:5173），用浏览器打开就行。
改了文件保存后，页面会自己刷新。

## 怎么改内容

有两种改法：

**① 在网页右侧的工具栏里改（最方便）**

| 按钮 | 能改什么 |
|---|---|
| 名字 | 卡片上的两行名字、第二行的颜色。页面底部的大字会跟着一起变 |
| 卡套 | 卡片会转到侧面、拆成三层：正面、中间的明信片、背面。每一层都能单独换模板、换底色、上传图片。直接点卡片上的某一层也能选中它，点「完成」就合上挂回去 |
| 绳子 | 挂绳颜色 |

- 改完会存在**这台电脑的这个浏览器**里，刷新后还在。换一台电脑或换一个浏览器就看不到了。
- 每个面板右上角都有「恢复默认」，点了就回到 `config.js` 里写的样子。

**② 改 `config.js`（改的是"默认值"）**

名字、颜色、左上角和右上角的小字、卡片上的标签、背面和明信片上的那句话、三页默认用哪个模板和底色，都在里面。

- 每个人是 `people` 里的一条。网址后面加 `?p=id` 就能切换到那个人，
  比如 `http://localhost:5173/?p=friend`。
- 想加一个朋友：把一整条 `{ ... }` 复制一份，改掉 `id` 和里面的字。

## 怎么玩

- 拖住卡片甩一甩。抓卡片的角，它会绕着你抓的那个点转。
- 双击卡片，它会转一圈，能看到背面。
- 点右侧工具栏的「卡套」，看卡片拆开的样子。
- 手机上用手指拖也可以。

## 文件说明

| 文件 | 管什么 |
|---|---|
| `config.js` | 默认的内容和颜色 |
| `badge.js` | 3D 吊牌、物理效果、拆开成三层的动画 |
| `card-texture.js` | 三页上的各个模板是怎么画出来的 |
| `toolbar.js` / `toolbar.css` | 右侧工具栏和弹出的面板 |
| `store.js` | 把工具栏里改的东西存进浏览器 |
| `style.css` | 页面排版：左上和右上的小字、底部大字 |
| `main.js` | 把上面这些拼起来 |
| `设计清单.md` | 字体、颜色、布局的具体数值 |

## 想发给不在身边的朋友

运行 `npm run build`，会生成一个 `dist` 文件夹。
把这个文件夹放到任意静态网站托管服务上（比如 Vercel），别人就能打开了。
